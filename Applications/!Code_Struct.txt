// 2. ENUMERATIONS & KEY DATA TYPES
//==============================================================================

  Chassis_State (Cust_Types.hpp):
    CALIBRATION     — HT8115 zero position calibration
    IDLE            — Legs hold current position (Kp=35, Kd=1.5, FFW=0)
    ENERGY_SAVING   — Legs extended (0°), wheels respond to joystick
    COMFORT         — Variable impedance suspension + body leveling
    CLIMBING        — Per-leg step-climbing kinematics + warp compensation
    FREE_CONTROL    — Trigger directly controls leg angle (0°~180°)
    DEBUG           — Debug output mode
    ERROR           — Error state

  MIT_Params:
    Position (rad), Velocity (rad/s), Pos_KP, Vel_KD, FFW_Current (A)

  Wheel_Leg_Params:
    Wheel_RPM, Leg_POS (deg), Leg_Force (N-m), Leg_RPM (rad/s),
    Leg_Kp, Leg_Kd, state

  Protocol::PC_Msg (13 bytes):
    Left/Right joystick (angle, radius), triggers, button status

  Protocol::Reachable_Msg (40 bytes):
    Motor positions, RPMs, temperatures (feedback to PC)

  COMFORT MODE (500 Hz):
  ┌────────────────────────────────────────────────────────────────────┐
  │ handleComfortMode(cmd)                                            │
  │  1. readAndTransformIMU()  — pitch, roll, accel_z, rates          │
  │  2. handleHeightButtons()  — button → height + bending direction  │
  │  3. Gather leg_currents[4], leg_angles[4] from Wheel_Legs        │
  │  4. impedance_.update(currents, angles, accel, rates, dt)         │
  │     ├─ Mass estimation: LPF(Σ|I|) × KA×GR / g                   │
  │     ├─ Warp error: mean(I_FL,I_BR) − mean(I_FR,I_BL)            │
  │     ├─ Per-leg Kp: r²sin²θ × kv_base × (1 − γ·warp_modulation) │
  │     ├─ Per-leg Kd: r²sin²θ × cv_base                            │
  │     └─ Per-leg FFW: −load·g·r·sinθ − warp_sign·warp·gain        │
  │  5. executeBodyControlImpedance(cmd)                              │
  │     ├─ PID: pitch/roll → per-leg height offset (±h_adj)          │
  │     ├─ h_i = target_height ± pitch_adj ± roll_adj                │
  │     ├─ Set_Leg_Height(h_i, v_i, kp_i, kd_i, ffw_i)             │
  │     └─ Inverse kinematics → wheel RPM → Execute                  │
  └────────────────────────────────────────────────────────────────────┘

  CLIMBING MODE (500 Hz):
  ┌────────────────────────────────────────────────────────────────────┐
  │ handleClimbingMode(cmd)                                           │
  │  1. readAndTransformIMU()                                         │
  │  2. handleHeightButtons()                                         │
  │  3. climbing_.update(feedback[4], dt) — per-leg FSM               │
  │  4. ground_contact_.update(currents[4], dt) — warp PI → ΔH       │
  │  5. PID leveling + climbing ΔH + warp ΔH → per-leg height        │
  │  6. Set_Leg_Height(h, v) → Execute                                │
  └────────────────────────────────────────────────────────────────────┘

  --- B. Impedance_Controller (Impedance_Controller.hpp / .cpp) ---

    Purpose: Variable impedance active suspension via MIT Kp/Kd/FFW modulation

    Derivation:
      Cartesian virtual spring/damper → Joint-space MIT parameters via Jacobian
      H = R + r·cos(θ)  →  Kp_MIT = r²·sin²(θ) × Kv (virtual stiffness)
                             Kd_MIT = r²·sin²(θ) × Cv (virtual damping)

    Algorithm (500 Hz, in update()):
      1) Mass Estimation:
         I_filter = LPF(Σ|I_i|, α=0.01)
         M_est = I_filter × KA×GR / g,  M_est ≥ 1.0 kg

      2) Body Vertical Velocity (for Skyhook — currently disabled):
         Leaky integrator + HPF on accel_z
         Per-leg velocity via rigid-body kinematics

      3) Warp Error (diagonal load imbalance):
         e_warp = mean(I_FL, I_BR) − mean(I_FR, I_BL)
         Deadband ±0.02A, clamped to ±3.0A

      4) Per-Leg Impedance (the core):
         Kp modulation: kv_i = kv_base × (1 − γ × warp_sign[i] × warp_norm)
           Overloaded diagonal → softer (retracts on obstacle)
           Underloaded diagonal → stiffer (holds height)
         Kd: cv_i = cv_base (fixed, skyhook disabled)
         Kp_MIT = clamp(r²sin²θ × kv_i, 2, 100)
         Kd_MIT = clamp(r²sin²θ × cv_i, 0.3, 4.5)
         Ramp blend: output = entry_Kp + α × (raw − entry_Kp), α: 0→1

      5) FFW Torque:
         Gravity comp: τ_grav = −load_per_leg × g × r × sin(θ)
         Warp offset:  τ_warp = −warp_sign[i] × warp_clamped × warp_ffw_gain
           → Pushes underloaded legs toward ground
           → Lightens overloaded legs (retracts from obstacle)
         Total: τ_ff = τ_grav + τ_warp

    Warp Sign Pattern:
      {FL:+1, FR:−1, BL:−1, BR:+1}
      Kp: +warp_sign → overloaded softens
      FFW: −warp_sign → underloaded pushes down (opposite direction!)

    Config Defaults:
      kv_base        = 800 N/m    (→ Kp ≈ 3.4 @ θ=90°)
      cv_base        = 250 N·s/m  (→ Kd ≈ 1.06)
      kv_warp_gain   = 0.5        (50% Kp redistribution)
      kv_min         = 100 N/m    (floor)
      warp_deadband  = 0.02 A
      warp_clamp     = 3.0 A
      warp_ffw_gain  = 0.25 Nm/A
      entry_kp       = 35         (transition start)
      entry_kd       = 1.5
      ramp_rate      = 0.005      (200 cycles to full)
      ka_times_gr    = 3.5        (KA=0.583 × GR=6)
      ffw_lpf_alpha  = 0.01       (mass estimation filter)
      leg_mass       = 0.5 kg

    Output Interface:
      getLegOutput(i) → { kp, kd, ffw_torque }
      getEstimatedMass(), getBodyVelZ(), getWarpError()


  --- C. Wheel_Leg (Wheel_Leg.hpp / Wheel_Leg.cpp) ---

    Purpose: One wheel-leg unit with 3-stage pipeline control

    Members:
      Motors::M3508 *wheel_motor
      Motors::HT8115 *leg_motor
      PID *Wheel_Vel_PIDs, *Leg_Vel_PIDs, *Leg_Pos_PIDs
      Wheel_Leg_Params info
      float leg_offset  (calibration)
      int bending_direction_ = 1  (+1 outward, -1 inward)

    Wheel Pipeline (3-stage):
      Set_Wheel_Target(rpm)
        → Add_Wheel_Compensation(rpm)
        → Execute_Wheel_Control()
        → Velocity PID → M3508 Command
      Zero-speed deadband: ±3 RPM

    Leg Pipeline (3-stage):
      Set_Leg_Target(pos, vel, force)
        → Add_Leg_Compensation(...)
        → Execute_Leg_Control()
        → Slew rate limiter + multi-turn unwrap
        → HT8115 MIT Mode: {θ, ω, Kp, Kd, FFW_current}

    Set_Leg_Height(h, v):
      h = R + r·cos(θ)  →  θ = arccos((h − R) / r)
      Apply bending_direction_: target_angle = θ × bending_direction_
      Singularity clamp near 0° and 180° (±10°)

    Set_Leg_Height(h, v, kp, kd, ffw_torque):  [Impedance overload]
      Same θ calculation, but overrides MIT Kp/Kd/FFW
      FFW current = ffw_torque / KA  (KA = 0.583)

    Key Algorithms:
      Wheel_Compensation():
        n_wheel = n_leg × (1 + (r/R) × cos(θ))

      VMC_Calculation(F_z):
        τ = F_z × r × cos(θ)


  --- D. GroundContact (Ground_Contact.hpp / Ground_Contact.cpp) ---

    Purpose: Warp (diagonal twist) compensator via PI control on ΔH

    Algorithm:
      e_warp = mean(I_FL, I_BR) − mean(I_FR, I_BL)
      Apply deadband (±0.15A), then PI control:
        warp_dh += ki × e_warp × dt
        total = kp × e_warp + warp_dh
        Clamp to ±max_warp_dh

    Per-leg ΔH pattern:
      FL: −dh,  FR: +dh,  BL: +dh,  BR: −dh

    Config:
      kp = 0.002 m/A,  ki = 0.0005 m/(A·s)
      max_warp_dh = 0.020 m
      deadband = 0.15 A

    Used by: CLIMBING mode (COMFORT uses Impedance_Controller's internal warp)


  --- E. Climbing_Dynamics (Climbing_Dynamics.hpp / Climbing_Dynamics.cpp) ---

    Purpose: Per-leg step-climbing kinematics with constant chassis height

    Enums:
      LegClimbPhase: IDLE → PREP → DETECT → CLIMBING → COMPLETE

    Per-Leg State Machine:
      PREP:     Set θ to prep angle, wait until reached
      DETECT:   Monitor wheel_current > threshold, confirm duration
      CLIMBING: Integrate β from wheel angular velocity
                θ̇ = √(R² − [R−h+L(1−cosθ)]²) / (L·sinθ) × φ_w
                Output: target_h = R + L·cosθ
      COMPLETE: Reset to IDLE

    Config:
      prep_theta_deg = 15°, wheel_current_threshold = 3.0 A
      detect_confirm_s = 0.050 s, theta_min_deg = 3°


  --- F. Controller (Controller.hpp / Controller.cpp) ---

    Purpose: Map joystick input to velocity commands

    Method: Map_Joystick_To_Velocity(PC_Msg, &vx, &wz)
      Left stick  → Forward/backward velocity  (angle 30°-150° / 210°-330°)
      Right stick → Rotation velocity           (angle 100°-260° / others)
      Deadzone: 200 LSB
      Scales to MAX_FORWARD_RPM / MAX_TURN_RPM


  --- G. PC_Comm (PC_Comm.hpp / PC_Comm.cpp) ---

//==============================================================================
// 10. COMFORT MODE CONTROL FLOW (FULL PIPELINE)
//==============================================================================

  INPUT: PC_Msg (Joystick, Buttons, Triggers)
         │
  1. CONTROLLER MAPPING
     Joystick → (Vx, Wz)
         │
  2. INVERSE KINEMATICS
     (Vx, Wz) → [FL_RPM, FR_RPM, BL_RPM, BR_RPM]
         │
  3. IMU SENSOR FUSION
     Read Euler (Roll, Pitch, Yaw), Accel (X,Y,Z), Gyro (pitch_rate, roll_rate)
     Correct IMU mounting offset (Roll = 182.91°)
         │
  4. ACTIVE SUSPENSION COMPUTATION
     Leg currents + Accel_Z + Omega_Roll + Omega_Pitch
     → Estimate mass (LPF) → Estimate damping C = 0.5√M
     → Integrate accel → HPF body velocity
     → Per-leg velocity (rigid body kinematics)
     → Skyhook: ΔH_i = -ρ × V_i
         │
  5. BODY LEVELING (PID)
     Roll PID  → ΔH left/right
     Pitch PID → ΔH front/back
         │
  6. HEIGHT DISTRIBUTION TO EACH LEG
     FL: h = h_base + Δh_pitch - Δh_roll + Δh_susp(FL)
     FR: h = h_base + Δh_pitch + Δh_roll + Δh_susp(FR)
     BL: h = h_base - Δh_pitch - Δh_roll + Δh_susp(BL)
     BR: h = h_base - Δh_pitch + Δh_roll + Δh_susp(BR)
         │
  7. HEIGHT → LEG ANGLE
     θ = arccos((h - R) / r)
         │
  8. WHEEL-LEG DECOUPLING
     Compensation = n_leg × (1 + (r/R) × cos(θ))
         │
  9. MOTOR CONTROL PIPELINE
     Wheel: Target RPM + Compensation → Vel PID → Motor Cmd
     Leg:   Target Angle + Compensation → Pos PID → Vel PID → Motor Cmd (GM6020)
                                        → Pos PID → MIT Cmd (HT8115)
         │
  10. CAN TRANSMISSION
      DJIMotor::transmit(3, 0) — GM6020 legs on CAN1
      DJIMotor::transmit(0, 1) — M3508 wheels on CAN2
         │
  11. FEEDBACK
      Collect RPM, position, force, temperature per leg
      → Package into Reachable_Msg → Send to PC via Serial


//==============================================================================
// 10b. CLIMBING MODE CONTROL FLOW
//==============================================================================

  On entry (Set_Mode → CLIMBING):
    reset PIDs + climbing_.reset() + climbing_.startClimbAll()
      → All legs transition IDLE → PREP
         │
  Per cycle (500 Hz):
         │
  1. READ IMU (shared: readAndTransformIMU)
     → chassis_pitch_, chassis_roll_, accel_z_, rates
         │
  2. BUTTON → TARGET HEIGHT (shared: handleHeightButtons)
     → target_chassis_height_ (used by non-climbing legs)
         │
  3. GATHER PER-LEG FEEDBACK
     For each leg: LegClimbFeedback = {
       leg_pos_deg   ← Get_LegPosition()
       wheel_rpm     ← Get_WheelRPM()
       wheel_current ← Get_WheelCurrentFeedback()   (M3508 current, A)
     }
         │
  4. CLIMBING STATE MACHINE (climbing_.update)
     Per-leg:
       PREP:     Output h = R + L·cos(prep_θ).  Wait for leg near prep angle.
       DETECT:   Hold prep_h. If wheel_current > 3A for 50ms → CLIMBING.
       CLIMBING: Integrate β += φ_w·dt.
                 θ from constraint: cosθ = (R+L-h-R·sinβ)/L
                 θ̇ from kinematic eqn. Output h = R+L·cosθ, v = -L·sinθ·θ̇.
       COMPLETE: β≥90° or θ≥θ_end → IDLE.
         │
  5. BODY LEVELING PID (same as COMFORT)
     Roll PID → Δh_roll,  Pitch PID → Δh_pitch
     Gyro Feedforward → v_pitch_ff, v_roll_ff
         │
  6. PER-LEG HEIGHT DISTRIBUTION (climbing-aware)
     For each leg i:
       If climbing (PREP/DETECT/CLIMBING):
         h_i = climbing.getTargetHeight(i) + leveling
         v_i = climbing.getTargetVelocity(i) + gyro_ff
       If IDLE:
         h_i = target_chassis_height_ + leveling
         v_i = gyro_ff
     → Clamp to [h_min, h_max]
     → Set_Leg_Height(h_i, v_i)
         │
  7. WHEEL VELOCITY CONTROL (shared)
     Joystick → IK → Wheel RPM → Compensation → Execute
         │
  8. EXECUTE ALL MOTORS
     Execute_Wheel_Control() + Execute_Leg_Control() per leg


//==============================================================================
// 11. KEY FORMULAS
//==============================================================================

  Wheel-Leg Decoupling:
    n_wheel = n_leg × (1 + r/R × cos(θ))

  Height ↔ Angle:
    h = R + r·cos(θ)   →   θ = arccos((h - R) / r)

  VMC (Force → Torque):
    τ = F_z × r × cos(θ)

  Active Suspension (Skyhook):
    Δh_i = -ρ × V_i,  where ρ = C/K,  C = 0.5√M

  Climbing Kinematics (Step Climbing):
    Constraint: cos(θ) = (R + L − h − R·sin(β)) / L
    θ̇ = √(R² − [R−h+L(1−cosθ)]²) / (L·sinθ) × φ_w
    β₀ = arcsin((R−h)/R)
    θ_end = arccos((L−h)/L)
    Output: target_h = R + L·cosθ,  target_v = −L·sinθ·θ̇

  Inverse Kinematics (Differential):
    FL/BL = Vx - Wz
    FR/BR = Vx + Wz
